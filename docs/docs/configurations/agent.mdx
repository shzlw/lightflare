# Agent

## Overview

The agent turns a user request into useful work. It can answer directly, use memory, call tools, follow skills, and adapt when tool results change what should happen next.

At a high level, an agent run works like this:

1. The agent reads the user request, relevant memory, available tools, and available skills.
2. It creates a short plan only for the work needed to answer the request.
3. Independent steps can run in parallel when they do not depend on each other.
4. Each step can call a tool, use previous step results, or produce a partial answer.
5. After a group of steps finishes, the agent checks whether the current plan is still right.
6. If results make the remaining plan unnecessary or wrong, the agent can replace the pending work.
7. The final answer is composed from the original request, retrieved context, tool results, and completed work.

This makes the agent useful for tasks that require more than one action. For example, it can retrieve memories, search a document, call a web or Slack tool, compare results, and then answer with the relevant evidence.

Parallel execution is used to save time when steps are independent. Adaptive replanning is used so the agent does not blindly follow an outdated plan after a tool succeeds, fails, or returns surprising information.

The agent settings control retry behavior, parallelism, maximum execution length, replanning limits, and final response refinement.

## Properties

| Variable | Default | Description |
| --- | --- | --- |
| `LIGHTFLARE_AGENT_MAX_STEP_ATTEMPTS` | `3` | Max attempts per agent step. |
| `LIGHTFLARE_AGENT_MAX_PARALLEL_STEPS` | `4` | Max parallel agent steps. |
| `LIGHTFLARE_AGENT_MAX_EXECUTION_WAVES` | `8` | Max execution waves for one agent run. |
| `LIGHTFLARE_AGENT_MAX_REPLANS` | `2` | Max adaptive replans for one agent run. |
| `LIGHTFLARE_AGENT_MAX_RESPONSE_RESOLUTION_ROUNDS` | `2` | Max response resolution rounds. |
| `LIGHTFLARE_AGENT_EXECUTION_EXECUTOR_CORE_POOL_SIZE` | `4` | Agent executor core pool size. |
| `LIGHTFLARE_AGENT_EXECUTION_EXECUTOR_MAX_POOL_SIZE` | `8` | Agent executor max pool size. |
| `LIGHTFLARE_AGENT_EXECUTION_EXECUTOR_QUEUE_CAPACITY` | `100` | Agent executor queue capacity. |
