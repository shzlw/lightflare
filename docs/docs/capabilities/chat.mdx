# Chat

## Overview

Chat is the main interactive experience for working with an agent. A user sends a message, the agent decides what work is needed, and progress is streamed back while the work runs.

Chat is designed for long-running work, not just instant responses. During a run, the UI can show:

- The plan the agent intends to follow.
- Which step is currently running.
- Tool calls and tool results.
- Intermediate progress messages.
- The final response.

This helps users understand what the agent is doing instead of waiting on a blank screen. It is especially useful when the agent needs to search memory, call external tools, inspect documents, or run scheduled-style work from a chat request.

Chat history can also feed memory. Useful facts from prior conversation can be saved or compacted so future runs have context without replaying the full transcript.

The chat executor settings control how many chat runs can stream at once and how much burst traffic can wait in the queue.

## Properties

| Variable | Default | Description |
| --- | --- | --- |
| `LIGHTFLARE_CHAT_STREAM_EXECUTOR_CORE_POOL_SIZE` | `4` | Chat stream executor core pool size. |
| `LIGHTFLARE_CHAT_STREAM_EXECUTOR_MAX_POOL_SIZE` | `8` | Chat stream executor max pool size. |
| `LIGHTFLARE_CHAT_STREAM_EXECUTOR_QUEUE_CAPACITY` | `100` | Chat stream executor queue capacity. |
