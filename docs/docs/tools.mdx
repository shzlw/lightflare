# Tools

Lightflare runs approved tools from one server-side environment instead of each user's local machine. Tool credentials and access are managed centrally.

## Integrations

Tools are grouped by integration. Enable an integration first, then configure the integration-specific credentials, allowlists, and runtime settings. Some integrations also let you allow only specific tools.

- [Slack](./tools/slack): collaboration and messaging.
- [Email](./tools/email): outbound email messages.
- [OpenMeteo](./tools/openmeteo): weather forecasts and geocoding.
- [Playwright](./tools/playwright): rendered web page extraction.
- [Brave Search](./tools/brave-search): current web search.
- [HTTP Client](./tools/httpclient): controlled HTTP requests to approved hosts.
- [Postgres](./tools/postgres): PostgreSQL schema discovery and read-only queries.
- [MCP](./tools/mcp): external tool servers that speak the Model Context Protocol.

Built-in workflow tools are documented with the [Workflow](./capabilities/workflow) capability.

## MCP Tools

MCP servers can add tools dynamically. MCP tool names are qualified by server so the agent can distinguish tools from different external integrations.

Use the integration-specific pages to configure required credentials, allowlists, and runtime settings.
